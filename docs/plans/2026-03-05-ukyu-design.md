# ukyu（有給管理アプリ）設計ドキュメント

作成日: 2026-03-05

---

## 1. アプリ概要

### 目的

- 個人の有給休暇を、視覚的に管理する
- 計画的な取得を、サポートする

### ターゲット

- LD（学習障害）・ディスレクシア対応を重視
- モバイル（iPhone）での利用がメイン

### デザインの方向性

- かわいく、ポップで、見やすい
- 長い文章は使わない
- 情報は短く区切って表示する

### アクセシビリティ方針

**フォント**
- UDデジタル教科書体 / Noto Sans JP
- 読みやすさを最優先

**文字サイズ**
- ベース: 16px 以上
- 重要な数字: 24px 以上

**行間・余白**
- 行間: 1.8 以上
- 要素間に十分な余白を確保

**配色**
- パステルカラーベースのポップな色合い
- コントラスト比 4.5:1 以上

**情報の伝え方**
- テキストだけに頼らない
- アイコンや絵文字で、直感的に伝える
- 長文を避け、短いフレーズで区切る

## 2. 機能一覧

### コア機能

**1. ダッシュボード（ホーム画面）**
- 残日数を、大きく表示
- 取得済み / 予定 / 残り を、ひと目で確認
- 繰越分と今年度分を、分けて表示

**2. カレンダービュー**
- 月表示のカレンダー
- 取得済みの日 → 色付きマーク
- 予定の日 → 別の色でマーク
- 日付タップで、有給の登録・編集

**3. 有給の登録**
- 日付を選ぶ
- 種類を選ぶ（全日 / 午前半休 / 午後半休）
- メモを入力（任意）
- ステータスを選ぶ（予定 / 確定 / 取得済み）

**4. 有給の付与・繰越管理**
- 年度ごとの付与日数を登録
- 前年度の残日数を、自動で繰越
- 消滅期限（2年）を管理
- 期限が近い分から、優先的に消化を促す

### サブ機能

**5. 残日数シミュレーション**
- 残りの日数で、どう使えるか提案
- 例:「全日 × 3回」「半休 × 6回」
- 組み合わせパターンを、わかりやすく表示

**6. データのエクスポート**
- JSON形式でバックアップ
- インポートで復元も可能

**7. 通知・リマインダー**
- 消滅期限が近づいたら通知
- Web Notifications API を使用
- PWA対応で、プッシュ通知風に

## 3. 技術構成

### 技術スタック

| 区分 | 技術 |
|------|------|
| ビルド | Vite |
| UI | React + TypeScript |
| スタイル | Tailwind CSS |
| データ保存 | IndexedDB（Dexie.js） |
| PWA | vite-plugin-pwa |
| 通知 | Web Notifications API |
| パッケージ管理 | pnpm |

### データモデル

**有給付与（Grant）**

| フィールド | 型 | 説明 |
|-----------|-----|------|
| id | string | 一意のID |
| fiscalYear | number | 年度（例: 2026） |
| grantDate | string | 付与日 |
| expiryDate | string | 消滅日（付与日+2年） |
| totalDays | number | 付与日数 |
| source | string | "new" / "carried" |

**有給使用（Usage）**

| フィールド | 型 | 説明 |
|-----------|-----|------|
| id | string | 一意のID |
| date | string | 使用日 |
| type | string | "full" / "am" / "pm" |
| status | string | "planned" / "confirmed" / "used" |
| grantId | string | どの付与分から消化するか |
| memo | string | メモ（任意） |

**設定（Settings）**

| フィールド | 型 | 説明 |
|-----------|-----|------|
| fiscalYearStart | string | 年度開始月日（例: "04-01"） |
| defaultGrantDate | string | 付与基準日 |
| hireDate | string | 入社日（勤続年数の計算に使用） |

**付与ルール（GrantRule）**

| フィールド | 型 | 説明 |
|-----------|-----|------|
| id | string | 一意のID |
| yearsOfService | number | 勤続年数 |
| grantDays | number | 付与日数 |

デフォルト付与日数（労働基準法）:

| 勤続年数 | 付与日数 |
|---------|---------|
| 0.5年 | 10日 |
| 1.5年 | 11日 |
| 2.5年 | 12日 |
| 3.5年 | 14日 |
| 4.5年 | 16日 |
| 5.5年 | 18日 |
| 6.5年以上 | 20日 |

### データの流れ

```
付与を登録 → 残日数を自動計算 → カレンダーで予定登録
                                    ↓
                          残日数リアルタイム更新
                                    ↓
                          消滅期限の近い分から自動消化
```

## 4. 画面構成とUI方針

### 画面一覧（モバイルファースト）

**ボトムナビゲーション（3タブ）**

| タブ | アイコン | 内容 |
|------|---------|------|
| ホーム | 🏠 | ダッシュボード（残日数表示） |
| カレンダー | 📅 | 月カレンダー + 有給登録 |
| 設定 | ⚙️ | 付与登録・エクスポート・設定 |

### 各画面の概要

**ホーム（ダッシュボード）**
- 残日数を、大きな数字で表示
- 円グラフやプログレスバーで、視覚的に把握
- 「今年度分」「繰越分」を、カードで分けて表示
- シミュレーション: 残りで何ができるか

**カレンダー**
- 月カレンダーを表示
- 有給の日は、色付きの丸で表示
- 全日 → 塗りつぶし丸
- 半休 → 半分塗りの丸
- タップで登録・編集のモーダル表示

**設定**
- 年度ごとの付与日数を登録
- 年度開始日の設定
- データのエクスポート / インポート
- 通知のON/OFF

### デザインテーマ

- **カラーパレット**: ラベンダー、ミントグリーン、ピーチピンク
- **角丸**: 大きめ（12px〜16px）で、やわらかい印象
- **カード型レイアウト**: 情報をカードで区切る
- **余白たっぷり**: 詰め込まない
- **アニメーション**: さりげない遷移で、楽しさを演出
